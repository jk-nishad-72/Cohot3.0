In our **Job Ready AI-Powered Cohort 3.0 @ Sheryians Coding School**,

👉 **Secure Authentication Flow**

---

💡 **What I learned today:**

• Difference between **Access Token & Refresh Token**
• Why access tokens are **short-lived (security first)**
• How refresh tokens help users stay logged in **without re-login**
• Token flow:
➡️ Login → Access Token + Refresh Token
➡️ Access expires → Use Refresh Token
➡️ Generate new Access Token

• Where to store tokens securely (cookies vs local storage 🤯)
• How backend verifies tokens before giving access
