### 🧠 Concepts that clicked today:

#### 🔑 JWT (JSON Web Token)

* `sign()` → Create token with user data + secret
* `verify()` → Validate token (Is the user legit?)
* `decode()` → Read token payload

#### 🔐 Password Security with bcrypt.js

* Hashing passwords before storing
* Comparing hashed passwords during login

#### 🏗️ Clean Backend Architecture

* Models → `auth.model.js`
* Routes → `auth.routes.js`
* Controllers → `auth.controller.js`
* Middleware → `auth.middleware.js`
* Config → Database setup

#### 🔗 APIs we created:

* `POST /auth/api/register`
* `POST /auth/api/login`
* `GET /auth/api/user` *(Protected 🔒)*
